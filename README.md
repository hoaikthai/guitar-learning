# Fretwise

Learn guitar melodies: pick a song, read the staff + tab, and follow the fretboard that shows which string and fret to press. Playback speed from 0.2× to 1.5×, step-by-step mode, bar looping, metronome and count-in.

HTML MVP of a future iOS (Swift) app. Open `index.html` in a browser — no build step.

Live: https://hoaikthai.github.io/guitar-learning/
